# HM2026 Spáleikur

Repoið (`dist/`) býr nú í GitHub-organization Verkhonnun: `https://github.com/Verkhonnun/hm2026-spaleikur` (gamla slóðin undir `maggibilli` áframsendist en á ekki að vera notuð). Síðan er hýst á GitHub Pages af `main` á `https://hm2026.verkhonnun.is`, þannig að deploy er einfaldlega push á `main` (Pages byggir sjálfkrafa, ~1 mín). Supabase er bara bakendi; verkstreymið `update-results.yml` notar leyndarmálið `SUPABASE_BOT_TOKEN` og er óvirkt þar sem mótinu er lokið.
